# DuduAdmin 功能图谱

状态：2026-09-30，首版前端已按 [Spec #68](https://github.com/Buktal/dudu/issues/68) 与 [原型](../prototype/dudu-admin/) 完成。正式程序只访问真实服务；本轮不包含 Server 编码、数据库验收或部署。

## 页面与操作

| 功能 | 入口与操作 | 前端状态 |
| --- | --- | --- |
| 登录与身份 | 独立登录页；真实认证、标签页身份恢复、失效退出、主动退出 | 已实现；退出清理本地身份，服务请求失败显示真实结果；后端不撤销 token |
| 环境选择 | 开发登录页及顶部下拉；本地/线上、修改本地地址 | 已实现；切换取消请求、清身份与页面；生产固定配置 |
| 企业查询 | 默认企业管理页；名称/六位 ID 搜索、状态筛选、分页 | 已实现；区分加载、空企业、无匹配与失败 |
| 企业开通 | 创建抽屉；六位 ID 随机生成或检测、企业资料、初始管理员 | 已实现；竞态保护、可用后提交、冲突保留表单 |
| 企业详情 | 企业名称、行菜单、概览最近开通记录 | 已实现；展示资料、状态、管理员，支持直接定位资源汇总 |
| 资料维护 | 详情或行菜单 → 编辑资料 | 已实现；ID 不可编辑，选填空值传 null，列表与详情重新读取 |
| 企业启停 | 详情或行菜单 → 停用/恢复确认 | 已实现；停用原因必填，失败保持原状态 |
| 管理员重置 | 详情 → 初始企业管理员 → 重置密码 | 已实现；明确企业、登录名、稳定员工 ID；确认密码后提交 |
| 运营概览 | 企业总数、启用/停用数、近 7 天开通、最近企业 | 已实现；返回值来自 HTTP，不在失败时补零 |
| 资源汇总 | 独立页面；按企业搜索筛选；从详情带入企业 ID | 已实现；员工总数/启用员工、用户组总数、渠道接入账号总数 |
| 操作记录 | 企业 ID、操作类型筛选及分页 | 已实现；展示时间、操作者、目标企业/用户、动作与说明 |
| 个人账号 | 当前非敏感身份、自身改密与取消 | 已实现；原密码错误不退出，成功后清身份并重新登录 |

企业内部员工、用户组、渠道账号编辑不在 Admin 中提供。资源汇总只展示当前接口定义的数量与员工启用状态，不推断渠道授权、连接健康或用户组启停。
