# DuduConsole 功能图谱

2026-10-20，首版[规格与验收方案](../design/dudu-console/README.md)定稿，**下表业务功能全部待实施**。不能以规划票关闭作为业务完成依据。

| 模块 | 功能与流程 | 当前状态 |
| --- | --- | --- |
| 企业认证 | 企业ID登录、当前企业/管理员恢复、退出 | 已定方案，待实施 |
| 个人账号 | 身份展示、验证原密码后改密 | 已定方案，待实施 |
| 员工 | 初始管理员创建、查找、改名、启停、角色与密码维护 | 已定方案，待实施 |
| 用户组 | 平级组创建、查询、改名，按管理权限可见 | 已定方案，待实施 |
| 成员 | 多组添加/移除、普通管理员只维护组内普通员工 | 已定方案，待实施 |
| 渠道账号 | 实际渠道字段、密钥只写、配置存在提示、回调地址、同账号维护与换组 | 已定方案，待实施 |
| Desk联动 | 管理写入提交后通知，按当前组重查接待与历史范围 | 现有部分基础机制可复用，Console链路待实施 |

限制：不包含企业运营、额外概览/操作记录页面、组/账号启停删除、OAuth向导或自动健康检测。实际渠道能力与配置限制见[字段表](../design/dudu-console/channel-fields.md)。
