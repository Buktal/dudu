# DuduConsole 功能图谱

2026-10-21，首版业务页面与 Server 接口已实施；检查结果与实际联调范围见[验收记录](../design/dudu-console/acceptance.md)，行为依据见[规格](../design/dudu-console/README.md)；前端机制层与 DuduAdmin 的复用边界见 [ADR-0016](../adr/0016-admin-console-controlled-copy.md)（受控拷贝与测试同步）

| 模块 | 功能与流程 | 当前状态 |
| --- | --- | --- |
| 企业认证 | 企业ID登录、当前企业/管理员恢复、退出 | 已实施，会话放 sessionStorage |
| 个人账号 | 身份展示、验证原密码后改密 | 已实施，成功后清当前会话 |
| 员工 | 初始管理员创建、查找、改名、启停、角色与密码维护 | 已实施，保护初始管理员 |
| 用户组 | 平级组创建、查询、改名，按管理权限可见 | 已实施，写入锁后重验权限 |
| 成员 | 多组添加/移除、普通管理员只维护组内普通员工 | 已实施，幂等增删 |
| 渠道账号 | 实际渠道字段、密钥只写、配置存在提示、回调地址、同账号维护与换组 | 已实施，13种适配器字段目录 |
| Desk联动 | 管理写入提交后通知，按当前组重查接待与历史范围 | 已实施，复用 access-changed |

限制：不包含企业运营、额外概览/操作记录页面、组/账号启停删除、OAuth向导或自动健康检测。实际渠道能力与配置限制见[字段表](../design/dudu-console/channel-fields.md)

## 企业翻译服务（2026-10-26）

新增翻译服务导航与配置页，初始企业管理员可维护多个常规或模型服务实例、选择企业默认服务、执行固定文本连接测试；凭据掩码读取，表单按各服务字段生成，配置 revision 防止旧页面覆盖

目录保留 Easydict 29 项来源对应，19 项提供网络适配，10 项明确显示环境、接口或范围限制，不将目录项目全部标为可用；企业真实凭据与生产调用仍需验证

2026-10-26 界面精修：翻译页采用默认服务管理与配置编辑分区，凭据字段响应式排列，连接测试逐卡反馈，暂不可用服务折叠，保存操作保持可达

## AI 助手模型选择（2026-10-26）

服务设置页改为「AI 与翻译服务」，初始企业管理员分别指定 defaultService 和 assistantService；助手下拉只列出通用模型服务，删除选中实例同时清空默认选择，保存继续校验修订并保留掩码凭据
