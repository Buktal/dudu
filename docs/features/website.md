# 项目官网功能图谱

范围：仓库根 `website/`。维护说明见 [website/README.md](../../website/README.md)

| 功能 | 入口与流程 | 状态及边界 |
| --- | --- | --- |
| 双语产品介绍 | `index.html` / `en.html`：定位、工作台预览、产品职责、渠道、部署与开源参与 | 静态页面，不调用业务 API |
| 接待导览 | 首页 `#demo`：可点击四步，或使用上一步／下一步完成来信、会话、回复与资料查看 | 固定示例数据；三个渠道场景；不是完整应用或真实在线试用；重置或切换渠道清除进度 |
| 产品截图 | 首页 `#products`：Desk、Console、Admin、MockPulse 页签与原图预览 | 统一单张浅色主图、比例与面板高度；公开页面仅保留演示说明，详细来源归维护文档；MockPulse 是网页预览局部，未验证桌面功能 |
| 主题 | 导航外观按钮、系统外观与本地偏好 | 页面及 消息动画同步切换，导览进度不受影响 |
| 渠道展示 | 首页 `#channels`：13 种正式接入的名称、图形或文字标识、配置说明入口 | 各渠道仍遵守自己的接入体系与权限；第三方图形不表示平台背书 |
| 使用指南 | `guides/`：部署、接待流程、三个渠道与 MockPulse，中英文共 14 页 | 操作指导链接源码契约；各页可返回接待导览 |
| 可访问性 | 原生按钮、状态播报、页签方向键、图片预览 Escape | 无 JavaScript 时保留图文内容和指南，导览显示说明；响应式布局 |

2026-10-21 改版与验证记录见[产品导览改版](../design/project-website/product-tour.md)

模块介绍页：`products/` 下 5 个模块各有中英文独立页面，顶部产品菜单、同级模块导航和首页入口可达。每页说明用途、主要功能、流程与使用范围，四个客户端展示截图，Server 展示消息流程。内容由 `docs/design/project-website/module-content.json` 与同目录生成脚本维护，sitemap 共 28 页

全站顶部导航统一于首页、模块页和文档页，保留当前位置和返回首页入口；窄屏产品菜单居中，完整入口可达。明亮主题采用暖白与珊瑚橙，暗黑主题保留

演示使用独立页面 `demo.html` / `demo.en.html`，全站演示入口和选中状态与实际页面一致。首页保留导览简介与入口。明亮主题采用中性白和灰色正文，珊瑚橙仅用于品牌动作与局部提示；步骤使用分段背景而非长分隔线
