# DuduDesk 功能图谱

记录当前前端工作台的功能、入口与限制。子项目概览见 [DuduDesk README](../../dudu-desk/README.md)，接口边界见 [API 契约](../../dudu-desk/docs/api-contract.md)。

## 功能与入口

| 模块 | 子功能与操作流程 | 状态与限制 |
| --- | --- | --- |
| 账户 | 恢复坐席身份 → 登录门禁 → 进入工作台；右上角头像查看坐席、设置或退出 | 前端流程与适配器契约已实现，真实 Server 认证待接入 |
| 接待布局 | 顶部切换专注、并排、卡片；共用会话、草稿和来访资料 | 已实现，接待模式保存为本地偏好 |
| 会话队列 | 搜索访客或消息；通过状态、来源和排序筛选；支持星标过滤 | 专注与并排在桌面宽度下固定显示，卡片复用顶部筛选；星标包含已结束会话 |
| 会话状态 | 状态下拉菜单显示全部、待回复、等待中、已结束及计数；会话内结束／继续接待 | “全部”表示当前未结束会话；已结束通过对应状态或星标查看 |
| 专注接待 | 选择队列中的会话 → 阅读完整消息 → 编辑并发送回复 | 窄窗通过返回按钮回到列表 |
| 并排接待 | 在会话标题内固定到右窗、取消固定或更换固定会话；两窗分别滚动、切换回复 | 桌面并排展示，窄窗通过主接待／固定标签切换；取消唯一固定会话时回到主窗 |
| 卡片接待 | 在卡片查看最新来信并回复 → 按需打开完整对话 | 头像与其他模式一致；卡片上可滚动列表；关闭滚动锚定避免 WebView2 回弹，短队列保留卡片、长队列按需渲染 |
| 消息历史 | 虚拟列表读取历史；向上加载较早消息；离开底部后可点击查看最新消息 | 已实现；真实历史、推送和回执由适配器接入 |
| 回复编辑器 | 插入表情、添加附件或选择快捷回复；插入后可继续编辑；发送并接待下一位 | 草稿按会话共享；接待下一位不会结束当前会话；完整刷新后草稿清空 |
| 来访资料 | 打开资料面板 → 查看渠道字段；复制全部渠道资料；维护星标、标签和内部备注 | 复制包含渠道、账号、字段及来源身份；缺失与空值分别保留；修改和错误保留反馈 |
| 主题 | 主题菜单选择十二款配色，点击即时应用 | 珊瑚橙默认且排第一，朱砂红第二；极夜黑为深色外观；三种模式共用偏好 |
| 帮助与快捷键 | 顶部问号查看三种接待布局示意、快捷键和输入提示 | 响应式弹窗；支持键盘关闭 |
| 桌面宿主 | Tauri 标题栏拖动、最小化、最大化／还原、关闭 | Web 运行时隐藏原生窗口操作 |

## 共享关系

- 三种接待模式组合共享的会话标题、筛选工具、消息列表、回复编辑器与来访资料组件。
- 并排的主接待、固定会话和当前回复对象由 inbox 状态管理；固定关系不会跨完整刷新恢复。
- 主题、接待模式和减少动态效果由本地偏好管理；账号、凭据及整个 store 不持久化。
- 渠道资料来自接待 API；复制不会把内部标签与备注混入渠道资料。

## 运行与验收边界

正式入口不使用模拟登录或假收发成功；开发数据需要按 [开发联调说明](../../dudu-desk/docs/development.md) 显式开启。当前功能可通过开发适配器验证，真实服务端认证、会话和收发接口仍待接入。
