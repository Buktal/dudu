# DuduDesk 功能图谱

记录当前前端工作台的功能、入口与限制。子项目概览见 [DuduDesk README](../../dudu-desk/README.md)，当前接口边界见 [InboxApi](../../dudu-desk/src/features/inbox/api.ts)，后端对接讨论见 [设计草案](../design/dudu-desk/data-contract.md)。

## 功能与入口

| 模块 | 子功能与操作流程 | 状态与限制 |
| --- | --- | --- |
| 账户 | 恢复坐席身份 → 登录门禁 → 进入工作台；右上角头像查看坐席、设置或退出 | 前端流程与适配器契约已实现，真实 Server 认证待接入 |
| 接待布局 | 顶部切换专注、并排、卡片；共用会话、草稿和来访资料 | 已实现，接待模式保存为本地偏好 |
| 会话队列 | “我的会话”旁图标打开查询浮层，包含搜索、状态、来源和排序；三行紧凑列表保留原信息 | 有筛选条件时图标显示圆点，清空后移除；Ctrl+K 打开搜索；三种模式共用；星标功能已移除 |
| 会话状态 | 状态下拉菜单显示全部、待回复、等待中、已结束及计数；会话内结束／继续接待 | “全部”表示当前未结束会话；已结束通过对应状态查看 |
| 专注接待 | 选择队列中的会话 → 阅读完整消息 → 编辑并发送回复 | 窄窗通过返回按钮回到列表 |
| 并排接待 | 在会话标题内固定到右窗、取消固定或更换固定会话；两窗分别滚动、切换回复 | 桌面并排展示，窄窗通过主接待／固定标签切换；取消唯一固定会话时回到主窗 |
| 卡片接待 | 只展示与左侧列表共用的最后一条消息摘要；点击回复展开编辑器，移出焦点收起 | 不再逐卡片预取历史；收起保留文字和附件草稿；完整对话按需分页；共用启动仍自动加载首位访客，后续对接统一；虚拟列表实现保留 |
| 消息历史 | 虚拟列表读取历史；向上加载较早消息；离开底部后可点击查看最新消息；消息时间默认隐藏，悬停或键盘聚焦时显示，隐藏常规回执 | 已实现；真实历史、推送和回执由适配器接入 |
| 回复编辑器 | 插入表情、添加附件或选择快捷回复；插入后可继续编辑；发送并接待下一位 | 草稿按会话共享；接待下一位不会结束当前会话；完整刷新后草稿清空 |
| 来访资料 | 打开资料面板 → 查看渠道字段；复制全部渠道资料；维护标签和内部备注 | 复制包含渠道、账号、字段及来源身份；缺失与空值分别保留；修改和错误保留反馈 |
| 主题 | 主题菜单选择八套柔和配色，点击即时应用 | 极昼白、极夜黑、栗木红、麦穗金、草木绿、牛仔蓝、烟岚紫、亚麻褐；七套浅色共用中性灰阶、文字与访客气泡，极夜黑使用炭灰与灰色气泡；气泡不显示描边，选中会话无深色侧边条；旧主题偏好按相近色系恢复，三种模式共用 |
| 帮助与快捷键 | 顶部问号查看三种接待布局示意、快捷键和输入提示 | 响应式弹窗；支持键盘关闭 |
| 桌面宿主 | Tauri 标题栏拖动、最小化、最大化／还原、关闭 | Web 运行时隐藏原生窗口操作 |

## 共享关系

- 三种接待模式组合共享的会话标题、筛选工具、消息列表、回复编辑器与来访资料组件。
- 并排的主接待、固定会话和当前回复对象由 inbox 状态管理；固定关系不会跨完整刷新恢复。
- 主题、接待模式和减少动态效果由本地偏好管理；账号、凭据及整个 store 不持久化。
- 渠道资料来自接待 API；复制不会把内部标签与备注混入渠道资料。
