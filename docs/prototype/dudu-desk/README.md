# DuduDesk · 统一接待工作台原型

一个工作台，顶部通过「自在 / 并肩 / 速答」选择接待方式，右上角通过「主题色」选择配色。仅使用本地演示消息；当前访客、消息、草稿、固定窗口与访客资料在切换模式时保留。

## 打开与修改

直接双击 `dudu-desk-prototype.html`，脚本、样式、字体均已内嵌，无需安装依赖。

修改原型时，在本目录运行：

```powershell
yarn dev
```

打开 [工作台原型](http://127.0.0.1:4317/)。修改后运行 `yarn build`，重新生成单文件。开发工具链复用 `dudu-desk` 已安装的依赖。

## 三种接待方式

| 模式 | 操作方式 |
| --- | --- |
| 自在 | 会话列表、完整聊天、访客资料，适合逐位接待。 |
| 并肩 | 左窗跟随会话列表，右窗手动固定一位访客，等待回复时继续处理另一段对话。 |
| 速答 | 每位访客一张最新消息卡，卡内直接回复，需要上下文时打开完整对话。 |

使用顶部固定的分段按钮切换：它们改变同一工作台的布局，左侧保留给会话和业务导航。切换时不清空草稿，也不会调换主接待与已固定的访客。并肩模式在窄窗口通过主接待 / 固定访客按钮切换可见窗口。

并肩会话采用一体化头部：姓名旁标注主接待或固定接待，右侧用「当前回复 / 切换回复」选择回复对象。移除独立状态条、卡片描边和头部分割线，当前窗口以柔和底色提示；访客信息与结束接待按钮保留在同一头部。

URL 参数为 `variant=A / C / E`，分别对应原方案 1 / 3 / 5；无效或已删除的模式参数自动回到自在。底部只保留演示状态、体验场景和模式说明。

## 12 款主题色

菜单按以下六组成对排列，便于左右比较。括号内为 URL 的 `palette` 参数。

| 对照方向 | 左列 | 右列 |
| --- | --- | --- |
| 温暖明快 | 杏桃橙 · 杏桃与草木绿（`apricot`） | 琥珀黄 · 暖白与柔麦金（`amber`） |
| 柔和轻盈 | 莓果粉 · 莓粉与暖白（`berry`） | 鸢尾紫 · 鸢尾与浅紫（`iris`） |
| 自然清新 | 海盐青 · 海盐与雾青（`sea`） | 松柏绿 · 松柏与苔绿（`pine`） |
| 商务沉稳 | 深海蓝 · 海军蓝与雾蓝（`ocean`） | 燕麦棕 · 燕麦与奶茶（`oat`） |
| 冷灰层次 | 岩墨灰 · 石墨与冷灰（`graphite`） | 雾白灰 · 雾白与冷灰（`fog`） |
| 纯粹日夜 | 极昼白 · 纯白与中性灰（`daylight`） | 极夜黑 · 极夜与碳灰（`midnight`） |

杏桃橙由青杏调整而来，保留橙绿搭配，以草木绿替换偏紫辅助色，并柔化主色；参数和已有偏好继续沿用 `apricot`。琥珀黄减少背景、消息气泡和资料卡的黄色面积与饱和度，以暖白打底。极昼白使用无彩中性色；雾白灰保留参考图更明显的冷灰分区，两者提供不同的明暗层次与色温。

主题菜单用两列展示配色小样，极窄窗口回到单列，标题与「完成」按钮始终可见。点击立即应用并保存，菜单保持展开以便连续试色；支持键盘左右浏览、Enter 选择，点「完成」、外部区域或按 Esc 收起。主题跨三种模式统一，选择记录在当前浏览器本地，下次从首页打开仍会沿用。显式 URL 配色优先于已保存的选择；无法使用本地存储时，当前会话与 URL 仍保留选择。

极夜黑同步适配聊天、输入框、菜单、提示和品牌字标；渠道身份颜色保留辨识度并调整深色可读性。

演示消息、草稿、标签和备注只保存在内存，刷新或「恢复初始演示」会重置；恢复演示数据不改变主题选择。

## 可体验的交互

- 会话搜索、渠道与状态筛选、星标、独立草稿、访客标签和接待备注。
- 文本发送、快捷回复、表情、示例图片和部分渠道的示例文件。
- 并肩模式固定、更换、收起与恢复第二窗；访客信息跟随当前回复对象。
- 速答卡片与完整对话共享草稿；新消息更新原卡，保持卡片顺序。
- 「体验场景」模拟新消息、发送失败与重试、回复限制与恢复。
- Enter 发送，Shift + Enter 换行，Ctrl + Enter 发送后接待下一位，Ctrl + K 搜索，Alt + 1 / 2 选择并肩窗口。

演示中两位不同来源的「林小满」拥有独立身份和草稿，不自动合并跨渠道访客。商品资料为手写演示数据；资料缺失、回复限制与发送结果遵循 [统一消息体验约束](../../research/dudu-desk/experience-constraints.md)。

## 样式与后续集成

原型的 `src/index.css` 直接导入正式 Desk 的 shadcn 基础样式，仅追加标准语义 token 的主题覆盖。布局样式按职责收敛，不再保留多层 `polish-*` 覆盖或另一套基础主题映射。12 个主题共用同一组变量；深色主题同时启用 shadcn 的 `.dark` 和原生 `color-scheme`，三种模式共用组件和消息样式。

集成落位、主题变量与迁移注意事项见 [集成说明](integration.md)。本轮改动位于原型目录，无新增第三方依赖。

```powershell
yarn lint
yarn check:type
yarn build
```
