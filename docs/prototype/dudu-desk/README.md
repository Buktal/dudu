# DuduDesk · 统一接待工作台原型

一个工作台，顶部通过「自在 / 并肩 / 速答」选择接待方式，右上角通过「主题色」选择配色。仅使用本地演示消息；当前访客、消息、草稿、固定窗口与访客资料在切换模式时保留。

## 打开与修改

直接双击 `dudu-desk-prototype.html`，脚本、样式、字体均已内嵌，无需安装依赖。

修改原型时，在本目录运行：

```powershell
yarn dev
```

打开 [工作台原型](http://127.0.0.1:4317/)。修改后运行 `yarn build`，重新生成单文件。开发工具链复用 `dudu-desk` 已安装的依赖。

## 三种接待方式

| 模式 | 操作方式 |
| --- | --- |
| 自在 | 会话列表、完整聊天、访客资料，适合逐位接待。 |
| 并肩 | 左窗跟随会话列表，右窗手动固定一位访客，等待回复时继续处理另一段对话。 |
| 速答 | 每位访客一张最新消息卡，卡内直接回复，需要上下文时打开完整对话。 |

使用顶部固定的分段按钮切换：它们改变同一工作台的布局，左侧保留给会话和业务导航。切换时不清空草稿，也不会调换主接待与已固定的访客。并肩模式在窄窗口通过主接待 / 固定访客按钮切换可见窗口。

URL 参数为 `variant=A / C / E`，分别对应原方案 1 / 3 / 5；无效或已删除的模式参数自动回到自在。底部只保留演示状态、体验场景和模式说明。

## 七款主题色

| 主题 | 配色方向 | URL 参数 |
| --- | --- | --- |
| 青杏 | 杏橙与草木绿，保留原配色 | `palette=apricot` |
| 海盐青 | 雾青与浅灰 | `palette=sea` |
| 莓果粉 | 莓粉与暖白 | `palette=berry` |
| 鸢尾紫 | 鸢尾与浅紫 | `palette=iris` |
| 岩墨灰 | 深石墨与冷灰 | `palette=graphite` |
| 深海蓝 | 海军蓝与雾蓝 | `palette=ocean` |
| 松柏绿 | 深松绿与苔绿 | `palette=pine` |

主题菜单展示配色小样，点击立即应用；支持键盘上下选择、Enter 确认、Esc 收起。主题跨三种模式统一，选择记录在当前浏览器本地，下次从首页打开仍会沿用。显式 URL 配色优先于已保存的选择；无法使用本地存储时，当前会话与 URL 仍保留选择。

演示消息、草稿、标签和备注只保存在内存，刷新或「恢复初始演示」会重置；恢复演示数据不改变主题选择。

## 可体验的交互

- 会话搜索、渠道与状态筛选、星标、独立草稿、访客标签和接待备注。
- 文本发送、快捷回复、表情、示例图片和部分渠道的示例文件。
- 并肩模式固定、更换、收起与恢复第二窗；访客信息跟随当前回复对象。
- 速答卡片与完整对话共享草稿；新消息更新原卡，保持卡片顺序。
- 「体验场景」模拟新消息、发送失败与重试、回复限制与恢复。
- Enter 发送，Shift + Enter 换行，Ctrl + Enter 发送后接待下一位，Ctrl + K 搜索，Alt + 1 / 2 选择并肩窗口。

演示中两位不同来源的「林小满」拥有独立身份和草稿，不自动合并跨渠道访客。商品资料为手写演示数据；资料缺失、回复限制与发送结果遵循 [统一消息体验约束](../../research/dudu-desk/experience-constraints.md)。

## 样式与后续集成

原型的 `src/index.css` 直接导入正式 Desk 的 shadcn 基础样式，仅追加标准语义 token 的主题覆盖。布局样式按职责收敛，不再保留多层 `polish-*` 覆盖或另一套基础主题映射。七个主题只改变颜色 token，三种模式共用组件和消息样式。

集成落位、主题变量与迁移注意事项见 [集成说明](integration.md)。本轮改动位于原型目录，无新增第三方依赖。

```powershell
yarn lint
yarn check:type
yarn build
```
