# DuduDesk 色系卡原型

2026-10-09 原型选色历史。问题：客服长时间阅读时，哪些柔和的主题强调色值得保留？用户最初选择八套：极昼白、极夜黑、枣木红、麦穗金、橄榄绿、牛仔蓝、烟岚紫、亚麻褐。本目录保留当时的候选与选择结果

后续用户已授权正式实施，并要求综合微信、飞书的深浅色参考调整全部主题。正式版已更新为栗木红、草木绿及统一中性灰阶，详见 [正式配色与验收记录](../../../design/dudu-desk/palette-refresh/README.md)。本原型不作为当前颜色契约，也不参与正式应用运行

[palette-cards.html](palette-cards.html) 是对话中的色系卡，目前展示白黑基准与六套已选彩色主题。所有浅色主题共享底色、面板、辅助灰、分隔线、正文与次要文字，只改变消息背景、选中背景、按钮与标记三档强调色。极夜黑单独使用深色灰阶。示例内容与排版完全相同，便于比较色彩；标题和正文不随主题染色

色系名称、灰阶、强调色与已明确排除的颜色集中在该文件的 `palette-study-data` JSON 中；`fixed` 记录白黑基准，`accents` 记录六套已选彩色主题。示例只使用静态内容，不访问账户、会话接口或工作台偏好。选择完成后移除排除复选框和反馈按钮，保留八套对照；不再读取此前的试选状态

## 已确认反馈

- 2026-10-09：选中会话只用整块柔和底色，移除深色侧边条
- 2026-10-09：用户明确不喜欢松针绿、青瓷色的青蓝感与偏亮观感，两款移出可选卡片
- 2026-10-09：用户进一步排除赤陶红、鼠尾草、雾海蓝、可可棕，并明确“选择好了”；白黑基准与其余六套确认保留
- 原型选择阶段偏暖、低饱和、不偏青，绿色当时保留橄榄绿；后续绿色调整见正式配色记录
- 本历史原型保留挑选时的色值；当时的任务范围仅为选色，正式应用保持只读

选色阶段按用户要求比较多种配色并保持同一布局，因此未采用通用 UI 原型流程中的三种布局变体。该阶段仅迭代仓库根下 `docs/prototype/dudu-desk/palette-study/`，没有合并实现或创建实施 Issue；后续正式实现已获得用户授权，另行记录于设计目录

