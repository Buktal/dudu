# 模板直发与素材分流：内置模板不入用户库，剧本可纯引用模板

「选中平台即见全部事件、点发即调试」的 demo 预置决定不落用户库：素材库列表按渠道筛选后直接列出全部内置事件模板（列表即目录，带「内置」徽标、按消息/事件分组），点任一模板即开草稿（名字默认取模板名）、即改即发——模板直发，发往该渠道现有连接（未配提示先建，多连接用最近一条可切换）；点保存才落为用户的事件素材，独立的新建弹窗保留。剧本步骤可直接纯引用内置模板：默认 payload 原样发、不可编辑、模板升版时已建步骤钉住创建时版本；要定制内容先另存为素材再引用

## Considered Options

- 首次启动 seed 全量入库：被否，250–350 条瞬间灌满用户库，删除后要不要恢复成为永久纠缠，版本机制对一次性 demo 空转
- 模板目录弹窗 / 独立目录页：被否，多一层点击不直观，列表即目录与既有素材库交互一致
- 剧本模板步骤可覆盖部分字段：被否，引用 + 覆盖合并后的模型、脏检测与展示过重；纯引用保持步骤「发的内容」语义二选一（只读模板或自己的素材）
