# 面向产品评估的官网与 README 改版

日期：2026-10-21。代码与配置路径相对仓库根；官网资源路径相对 `website/`

> 下方记录首轮改版；涉及移除动画、双图及明暗配对的选择已由文末“反馈后整体修订”取代。当前实现以该节为准

## 目标与实施选择

用户反馈 README 与官网内容复杂，希望提供演示、增加现有图片、协调明暗主题、美化渠道标识，并保持开源项目对外文案的专业性。用户确认首要受众是评估产品的使用者，演示采用官网内无需登录的交互式导览，首期聚焦坐席接待，其他应用图文展示；后续授权自主调整整体结构与文案

采用“用途 → 实际界面 → 接待导览 → 应用职责 → 渠道与限制 → 部署入口”的官网顺序。README 采用“用途 → 按目标阅读 → 团队使用流程 → 适用条件 → 渠道 → 仓库和运行”的顺序。技术文档保留详细字段、协议与实现依据；产品介绍优先采用使用任务表达，不增加未经实现验证的能力

## 反馈后整体修订

用户后续明确授权持续自主调整，并指出初次访问者不知如何进入下一步、页签切换使整页高度变化、截图数量和色调不一致、内部截图时间不应出现在产品文案、关键使用范围不应折叠。随后新增顶部产品菜单与独立模块介绍页需求

最终调整

- 恢复首屏科幻消息流动画，保留明确接待导览入口。取消容易被误认为页签的静态截图区域说明
- 导览四步均可点击，增加固定位置的上一步／下一步，按钮包含下一动作。直接选择步骤展示对应预设状态；重复体验和切换渠道可重置。预览区固定高度并在内部滚动，来访资料在对应步骤中优先展示。移除与可见引导重复的状态段落，仅保留辅助技术播报

- 公开文案与 README 不再出现截图日期、验收、联调或源文件等维护信息。来源记录仍保留在内部设计资料与 `website/README.md`。旧的双图、暗色图片等新增而不再引用的 WebP 已删除，原公开 PNG/JPG 地址保留
