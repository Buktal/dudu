# DuDu / 嘟嘟 · 表情 D · U 形眼睛版

这是额外的第二种风格，所有新文件均保存在本目录。[第一版“双 D · 双向对话”](../double-d/README.md)及其文件包保存在同级的 `double-d/` 目录

## 设计

大 D 藏在柔软的消息气泡轮廓里：左侧略倾斜，顶部轻轻隆起，右侧保留饱满的弧线，下方收出一个短小的消息尾角。它首先是消息容器，同时保留 DuDu 首字母的线索

两个小 U 始终保持开口朝上，不翻转。两只眼睛的上端等高、彼此略微拉开，底部保留舒展的圆弧，去掉向内压的倾斜。它们保留 DuDu 中 U 的线索，并通过圆润形状减弱生硬的字母感

标志由柔软的 D 形消息气泡和两只 U 形眼睛组成。两只眼睛直接镂空，可以透出实际背景色

沿用原版的信号橙、深墨色和自绘 DuDu 字标，让两个方向保留同一品牌的联系。AI 的暗示主要由表情承担

## 使用

- 信号橙：`#F2673C`；深墨色：`#232B33`；暖白色：`#F8F5EF`
- 独立图形：`256 × 256`；建议显示尺寸不小于 24 px，16 px 使用 favicon 版本
- 横版：`672 × 192`；等比缩放，建议宽度不小于 168 px
- 正式图形仅使用矢量路径。两只眼睛是 even-odd 路径里的透明镂空，无需遮罩
- 英文字标沿用原版自绘路径，不依赖外部字体。所有正式 SVG 均无位图、外链或脚本
- `currentColor` 版本可修改 SVG 根元素的 `color` 属性；通过 `<img>` 加载时，父页面的文字颜色不会自动传入文件
- 中文说明仅用于预览，不属于正式 logo
