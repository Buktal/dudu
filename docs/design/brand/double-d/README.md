# DuDu / 嘟嘟 Logo

设计方向：**双 D · 双向对话**

两个相向的 D 形消息气泡交叠，代表消息的接收与发送。交接处的透明留白保留两条通道的轮廓；整体组成一个紧凑的连接符号，呼应统一消息接口。圆润的转角延续“嘟嘟”的亲和感，厚实的几何结构适用于工具、文档和开发者产品

## 文件

| 文件 | 用途 |
| --- | --- |
| `dudu-logo.svg` | 默认横版，橙色与深墨色，适合浅色背景 |
| `dudu-logo-dark.svg` | 橙色与暖白色横版，适合深色背景 |
| `dudu-logo-mono.svg` | 单色横版，默认深墨色，可通过内联 SVG 的 `color` 改色 |
| `dudu-mark.svg` | 独立双色图形 |
| `dudu-mark-mono.svg` | 独立单色图形，默认深墨色 |
| `dudu-mark-white.svg` | 独立纯白图形，适合深色或品牌色背景 |
| `dudu-wordmark.svg` | 独立 DuDu 英文字标 |
| `dudu-app.svg` | 橙底白色应用图标 |
| `dudu-favicon.svg` | 浏览器标签图标，加大留白，建议用于 16–32 px |
| `preview.png` / `preview.svg` | 整体视觉预览，不作为正式 logo 使用 |
| `dudu-mark.png` / `dudu-app.png` | 1024 px 透明图形、512 px 应用图标，便于快速预览 |

## 颜色与尺寸

- 信号橙：`#F2673C`
- 深墨色：`#232B33`
- 暖白色：`#F8F5EF`
- 横版 SVG 比例：`672 × 192`，请等比缩放；建议显示宽度不低于 168 px
- 独立图形：`256 × 256`；建议显示尺寸不低于 24 px。16 px 使用 favicon 版本
- 图形周围保留至少一个笔画宽度的空间，避免与边框或其他内容紧贴

所有正式 SVG 均为独立矢量文件；字标由自绘路径组成，不依赖字体、位图、外部链接或脚本。除应用图标外，正式 SVG 的背景均透明。交叠处使用标准 SVG luminance mask，留白会透出实际背景色

`currentColor` 版本在内联使用时可修改 SVG 根元素的 `color` 属性；通过 `<img>` 加载时，外部页面的 `color` 不会自动传入 SVG。多个副本内联到同一页面时，应为各副本的 mask、title 和 desc ID 添加唯一前缀，并同步修改相应引用
