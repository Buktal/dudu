## Parent

[DuduDesk 对接 Spec：共享接待、访客名片与消息同步 #84](https://github.com/Buktal/dudu/issues/84)

## What to build

接通结束和继续接待，所有有权端显示后端保存的同一状态，历史与固定会话保持。

按已确认功能直接实现，字段与基本报文以最终数据契约为准。沿用现有组件、适配器、鉴权和数据库能力，不新增可靠投递、重放或并发协调框架。

## Acceptance criteria

- [ ] 结束将 visitor.status 写为已结束；继续沿用现有前端的待回复。只改接待状态，保留消息、名片及合法草稿。
- [ ] 保存后返回并通知完整访客摘要，各模式、状态筛选和计数同步。
- [ ] 结束后再次来信仍复用访客和历史，后端更新为待回复并通知入列。
- [ ] 按后端实际处理顺序生效，不增加前端并发裁决、结束基线或额外确认。
- [ ] 所有接口及通知执行既有企业/组权限；两个真实客户端验证结束、继续、再次来信及重登结果。
- [ ] 完成 Desk 类型检查/lint/相关测试和 Server 编译/相关测试，核验实际操作与状态菜单。
