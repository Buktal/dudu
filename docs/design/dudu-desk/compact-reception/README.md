# 接待工作台紧凑布局

日期：2026-10-08。实现位置：仓库根目录下 `dudu-desk/`。本目录为本轮设计与验收产物

## 设计选择

保留现有主题语义色、Inter 与系统中文字体，以及品牌、渠道标识。通过压缩留白和按需展开提高客服扫描效率，不另设一套配色或字号系统。列表仍保留姓名、星标、等待时间、摘要、渠道、账号、消息数和未读数

- 桌面顶部由最小 64px 调整为 48px；模式按钮高 28px
- 会话标题由最小 84px 调整为 60px；并排模式继续保留固定会话操作行
- 列表上下内边距由各 16px 调整为各 8px，三行间距由 6px 调整为 2px，头像 32px。常规行约 78px，原布局约 102px
- 查询条件集中在标题旁的浮层内，筛选标记沿用现有查询谓词，排序不算筛选
- 来访资料标题固定 44px
- 时间与正常回执放在气泡朝向聊天区中央的外侧窄列：来信右侧放时间，客服消息左侧分两行放时间和回执，底部对齐。删除重复的勾选图标，正文独立。失败重试与未确认提示在下方保留。此方案取代最初的气泡内尾部布局；原始验收截图留作本轮迭代记录，最新效果见 [外侧信息列](message-meta-outside.jpg)
- 卡片采用“最后一条客服回复及后续消息”，范围基于已加载历史；没有客服回复时回退到最近三条。完整对话查阅更早历史。保持卡片高度，消息区独立滚动
- 输入框默认收起，点击回复展开并聚焦；点击外部或键盘焦点离开后收起，草稿与附件保留。编辑器浮层内的操作不收起编辑器

## 仅时间布局修订

按用户最新要求隐藏已读等常规回执。来信时间在气泡右侧，客服消息时间在左侧，朝向聊天区中央，与正文末行对齐。间距 8px，时间占宽 32px，不增加行高；发送失败与结果未确认仍保留操作提示。取代上文的两行时间/回执方案，最新截图见 [仅时间布局](time-only.jpg)

## 时间按需显示（2026-10-09）

时间默认隐藏，悬停或键盘聚焦对应消息时显示，移出后隐藏。保留时间宽度，不改变气泡位置；失败与未确认提示保持可见。此规则取代之前的时间常驻显示
