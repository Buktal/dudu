# 翻译界面精修与验证

日期：2026-10-26

## 设计取向

服务对象为维护企业翻译接入的初始企业管理员，以及阅读双语消息的坐席

后台以配置清楚、操作可达为目标，工作台以保持对话阅读节奏为目标

沿用已有主题令牌，不引入新字体或依赖

| 角色 | 现有浅色主题基准 | 用途 |
| --- | --- | --- |
| 雾灰 | #F6F8FB | 页面底色 |
| 墨蓝 | #243345 | 主文本 |
| 白色 | #FFFFFF | 配置表面 |
| 珊瑚 | #C74E32 | 默认服务与主要操作 |
| 边界灰 | #E1E7EF | 表单与内容分区 |
| 辅助灰 | #647181 | 辅助说明 |

标题沿用 Inter 与系统中文回退字体，24px、600 字重和紧凑字距；正文 14px，说明 12px，译文标签与服务来源分别降至 11px 和 10px

## 后台布局

- 宽屏采用服务管理栏与配置编辑区，默认服务和添加入口集中在左侧
- 配置卡使用服务类型图标和企业默认标记区分身份，不添加装饰性统计
- 凭据字段宽屏并列、窄屏纵向排列，已保存秘密使用占位说明而不展示保留标记
- 连接测试反馈显示在对应服务卡内，不挤占全局保存反馈
- 暂不可用的服务默认折叠，保留原因查询入口
- 保存栏固定在视口底部附近，长表单仍有可达的操作入口
- 管理栏不固定高度或吸顶，避免短视口中其下方入口永久被保存栏覆盖
- 复核后删除无操作价值的页头说明徽标，将强调集中在企业默认服务

## 工作台细节

- 原文与译文使用细分隔和留白区分
- 目标语言显示可读名称，服务来源降为辅助文字
- 翻译入口使用轻量按钮，重新翻译改为带可访问名称的图标按钮
- 收起与展开使用方向图标，进行中复用 Spinner 并尊重减少动态效果设置
- 设置区采用分组语义、阅读语言标签和简短说明

## 浏览器验证

使用真实组件与固定响应验证，不读取企业凭据或访问供应商

- 后台在实际 ConsoleLayout 中检查宽屏与暗色主题
- 在 390px iframe 视口检查后台单列布局、表单换行、滚动及保存栏
- 检查 Desk 双向译文和设置区的宽屏与 390px 排版
- 实际操作连接测试与保存，确认反馈就近显示，已保存凭据无需重新填写也可保存
- Console 89 项测试与 Desk 翻译 5 项测试通过
- 两端 lint、类型检查和生产构建通过，临时预览文件在验证后清理

## 复现

在仓库根执行以下任一命令，打开对应地址，停止进程后脚本清理项目根的临时文件

```powershell
pwsh -NoProfile -File docs/design/dudu-desk/translation/preview.ps1 -Project console
# http://127.0.0.1:1425/.translation-preview.html
# 暗色在地址后追加 ?theme=dark

pwsh -NoProfile -File docs/design/dudu-desk/translation/preview.ps1 -Project desk
# http://127.0.0.1:1423/.translation-preview.html
```

固定数据源分别为 preview-console.tsx 与 preview-desk.tsx，预览页面不构成可用翻译服务或真实接口验收

窄屏复现时为命令追加 `-Narrow`，打开相同端口的 `/.translation-mobile.html`，页面使用 390×700 iframe 视口
