- 验证 1440×900、1280×720、900×700、360×520 的布局；窄窗保留返回列表、回复、附件、资料与固定窗入口，无横向溢出。
- 十二主题按六组连续切换，只有极夜黑使用深色；聊天、输入、附件、菜单与浮层同步变化，试色不清草稿或附件，Esc 返回主题按钮。
- 同名的不同渠道/账号保留独立草稿。并肩固定、收起、恢复、Alt + 2、窄窗切换正常；速答第三会话切回并肩后成为可见主窗，固定会话保持。
- 速答卡片与完整对话共享编辑；完整对话打开时焦点落在标题，避免误触接待操作；图片预览可嵌套打开和关闭。
- 本地 PNG 与文字文件经历准备、待发送、提交、受理；发送成功清理本次草稿，另一会话草稿保留；没有把受理显示成送达或已读。
- 标签和备注保存有确认反馈；Ctrl + K 可从窄窗聊天进入搜索，无结果与正常列表状态可区分。
- 完整刷新后保留主题和模式，草稿、附件、固定对象及上次回复选择均不恢复。默认队列选择属于本次新运行。
- 输入法组合键、迟到响应、失败/未确认发送、附件限制变化、资源清理及实时乱序由公共工作流回归测试覆盖；没有按三种布局复制业务测试。

当前工具没有原生 Windows 窗口交互能力，因此桌面验证限定为实际进程启动与再次启动；逐控件交互在浏览器完成。没有将原生窗口手工操作或系统输入法候选框测试记为已执行。

固定基线 `f2e22f43d07b1811e365965b04d6f6cd05b5a35b`；范围仅本次 Desk 与原型 README 收尾改动。独立 Standards 审查初次发现 1 项规范偏离、2 项设计判断，全部修复并复核：

## Spec 审查

独立 Spec 审查初次发现 4 项行为问题，均补公开回归并修复：

1. 取消历史分页后停留在 loading：取消恢复可加载状态，保留已读内容和游标，旧响应不能回写。
2. 旧列表响应覆盖刷新期间的新会话：按请求前版本保留期间变化，维持顺序，后续权威刷新仍可移除旧行。
3. 速答切回并肩后回复对象不可见：进入并肩时对齐主窗或恢复固定窗，不改变回复对象及选择版本。
4. 结束接待等 API 响应未同步筛选成员：会话快照统一更新查询成员，无需依赖额外订阅事件。

最终 Spec 剩余发现：0。另修复旧回执错误解除较新发送锁的问题，回归验证后续文字和附件仍保留。
