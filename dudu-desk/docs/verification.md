2026-09-16。实现依据为[规格 #50](https://github.com/Buktal/dudu/issues/50)、实施票 #51–59，以及用户随后提出的原型对齐与八项界面调整。本轮检查范围是 `dudu-desk/` 和临时目录忽略项；基线为 `a5cef7571c8ed3008c55d4ca7be329d4b3d25802`，不包含其他任务对 MockPulse 或根规范文件的修改。

## 本轮完成的实现

原交付 `1d4282f` 包含前端基础流程，但遗漏了原型中的排序、搜索范围、继续接待、部分固定选择与布局行为。本轮逐项修正这些差异，不能用上一轮的通过记录代替本轮验收。

| 范围 | 当前实现 |
| --- | --- |
| 窗口与空间 | 关闭 Tauri 原生装饰，提供随主题变化的最小化、最大化／还原、关闭；顶部空白可拖动和双击最大化；中窄窗口收紧布局 |
| 长列表 | 访客队列、消息历史、固定访客选择器使用 Virtuoso；速答使用 VirtuosoGrid；消息按需补读，提供回到最新消息 |
| 界面文案 | 移除开发／演示说明与底部连接栏；连接正常时不占空间，异常时顶部保留可重连图标 |
| 筛选与帮助 | 状态、搜索、来源和排序层次明确；清除筛选用图标；三种模式的说明集中到顶部帮助入口 |
| 三种布局 | 恢复自在、并肩与速答的区域比例、头像、消息气泡和输入区；删除速答口号与并肩常驻教程，保留回复目标 |
| 主题与样式 | 十二主题与 shadcn 共用 `src/index.css`；来源标识使用同一文件的语义变量；未增加第二套 CSS 或修改已确认主题值 |
| 查询与排序 | 默认未结束会话，支持等待最久／消息最多；使用真实等待起点和总消息数；搜索覆盖身份、来源、标签与完整历史 |
| 稳定接待 | 固定选择器与下一位查询独立；速答保留卡片顺序；全局下一位位于当前筛选外时打开完整对话 |
| 接待闭环 | 继续接待保留真实渠道能力；标签可逐个增删；草稿、附件和发送目标隔离；主题与模式跨重启保存，其余临时状态不恢复 |
| 体验数据 | 固定种子的 36 个会话、8 类渠道、不同等待时长与消息量、同名不同账号、连贯历史及媒体／限制场景 |

未新增依赖，未修改 `components/ui/` 生成物。所有业务代码与测试文件保持在 500 行以内。原型保留为只读参考，未复制其 CSS 到正式运行入口。
