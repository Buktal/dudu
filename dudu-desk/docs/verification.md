# Desk 前端迁移与本轮修正记录

2026-09-16。实现依据为[规格 #50](https://github.com/Buktal/dudu/issues/50)、实施票 #51–59，以及用户随后提出的原型对齐、界面收尾、账户入口、控件统一和过渡动效。最新改动仅限 `dudu-desk/`，不包含其他任务对 MockPulse 或根规范文件的修改。

## 账户、共用控件与动效（基线 e1486fd）

| 范围 | 本次修改 |
| --- | --- |
| 账户入口 | Header 右上角头像菜单，包含坐席信息、工作台设置、退出登录；资料与设置共用弹窗外壳，关闭时保留内容直到动画结束 |
| 设置 | 复用同一主题选择器与接待方式控件，追加减少动态效果偏好；与 Header 修改同步并自动保存 |
| 账户流程 | `features/account` 提供认证适配器、恢复身份、登录表单、退出确认、失败重试及请求取消；凭据由适配器持有 |
| 会话控件 | `ConversationHeader` / `ConversationActions` 统一三种模式的身份、状态、星标、结束／继续接待与资料开关 |
| 队列与图标 | `ConversationSidebar` / `QueueTools` / `presentation.ts` 统一标题、状态、数量与排序；卡片也可选择等待最久或消息最多；面板图标只在 `WorkspacePanelToggle` 中定义 |
| 动效 | 复用已安装的 `motion/react`，模式和会话短距离淡入、面板宽度与间距同步过渡；系统或个人减少动态效果设置生效，退出中的布局停止响应快捷键，收起面板不可聚焦 |

账户与接待 feature 通过 `App` 组装；身份确认后才建立 inbox，工作区上下文使用账户返回的坐席与工作台标识。退出成功清理请求、订阅、草稿、附件与固定对象，失败保留原会话供重试。正式认证仍未接入，默认登录页明确返回服务不可用；开发账号仅在开发适配器存在，详见 [开发联调](development.md)。

新增的逻辑回归覆盖登录元数据、凭据传递、失败重试、重复提交、迟到响应和销毁取消，以及减少动态效果偏好的兼容与恢复。全应用 smoke 从账户菜单退出，确认 inbox 请求取消和退订，再通过登录表单进入另一坐席／工作台，验证使用全新上下文。

## 原型对齐修正（918d7d7 历史记录）
