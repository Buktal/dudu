DUDU Server / Server

Connect channel integrations, access control and agent workflows.

The shared server for DuDu applications, handling authentication, organization and group access, channel messages, conversation storage and real-time updates.

Key capabilities

Authentication and access

Verify user identity and scope data access by organization and group.

Channel integrations

Handle callback verification, message parsing and supported messaging for implemented channels.

Conversations and profiles

Store visitor details, conversations and messages for consistent client access.

Real-time updates

Notify workspaces of incoming messages and conversation-access changes.

How it works

  1. Deploy the database and server, then configure the environment.
  2. Run the administration apps and workspace, then create organizations, teams and channel accounts.
  3. Configure public callback URLs and validate messaging after platform authorization.

Requirements and scope

The server is not an independent support interface; use it with the administration apps and workspace. Production deployment requires replacing development credentials, configuring public URLs and validating channels.

The modules work together: Admin provisions organizations, Console configures teams and channels, Desk handles conversations, and Server provides shared services. MockPulse is an optional development tool.
