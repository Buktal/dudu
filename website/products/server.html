DUDU Server / 服务端

连接渠道接入、权限与坐席接待。

DuDu 各应用共用的服务端，负责认证、企业与用户组权限、渠道消息处理、会话存储和实时更新。

主要功能

认证与权限

校验用户身份，按企业和用户组控制数据访问范围。

渠道接入

处理已支持渠道的回调验证、消息解析与指定收发能力。

会话与资料

持久化来访资料、会话和消息，为各客户端提供一致数据。

实时更新

通过实时通知向工作台提供来信和接待范围变化。

使用流程

  1. 部署数据库与服务端，完成环境配置。
  2. 运行管理端与工作台，建立企业、团队和渠道账号。
  3. 配置公开回调地址，在平台授权后验证实际收发。

使用条件与范围

服务端不是独立的客服界面，需要配合管理端与工作台使用。生产部署须替换开发凭据、配置公开地址并完成渠道验证。

各模块配合使用：Admin 开通企业，Console 配置团队与渠道，Desk 负责接待，Server 提供共用服务。MockPulse 为可选的开发联调工具。
