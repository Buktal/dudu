使用 MockPulse 联调渠道回调

使用可复现的事件素材、场景、计划和运行记录，验证 DuDu 本地回调与坐席工作流。

本页内容定位与运行方式建立可复现用例验证边界下一步

定位与运行方式

MockPulse 是仓库内可选的渠道回调模拟工具，不是客服生产服务。它由 React 前端与 Tauri / Rust 桌面能力组成；Web 预览不等于具备全部原生执行能力。

cd mock-pulse
yarn install
yarn tauri:dev

运行桌面应用前，按 MockPulse README ↗ 准备 Rust 与当前系统的 Tauri 构建环境。yarn dev 仅用于 Web 预览。

建立可复现用例

  1. 先运行 DuDu Server、Console 和 Desk，创建企业、员工、用户组及目标渠道账号。
  2. 按目标适配器准备事件素材和场景，使用与测试账号一致的签名、加密和回调配置；不要将任意 JSON 当作通用渠道请求。
  3. 将场景组织为测试计划并执行，结合运行记录与 Server 响应定位失败。
  4. 核对 Desk 中的来信、顺序、历史和当前访问范围；需要发送验证时另行准备真实发送凭据及可用的官方接口。

验证边界

本地受控回调可验证协议处理与接待链路，但不能证明真实平台已授权、公网回调可达或平台生产审核通过。模拟来信不会自动模拟官方出站 API。真实平台接入需独立记录验收结果。

下一步

按微信公众号、Telegram或WhatsApp指南完成对应平台准备。实现范围与运行限制以 MockPulse 源项目说明 ↗ 为准。
