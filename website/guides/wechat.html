微信公众号接入指南

为 DuDu 配置微信公众号明文回调、接收 token 与文本发送凭据，并验证统一工作台接待。

本页内容适用范围配置与验收排查与限制配置依据

适用范围

本页针对微信公众号 wechat-mp 适配器，当前仅支持明文回调。微信小程序与企业微信使用不同适配器和配置，不能套用本页字段；公众号 AES 密文模式不在当前支持范围。

配置与验收

  1. 在官方平台准备具有所需消息接口权限的公众号；将 Server 回调 origin 配置为平台可达的公开地址。
  2. 在 Console 新建微信公众号渠道账号并绑定用户组。填写接收 token；需要回复时补齐 appId 与 appSecret。
  3. 复制 Console 返回的回调地址到公众号服务器配置，token 必须一致，并选择明文消息模式。GET 校验通过后再启用消息回调。
  4. 从公众号用户端发送测试消息，在有权员工的 Desk 中检查来信与历史；再发送纯文本回复，核对官方平台返回的实际结果。

排查与限制

服务器配置验证失败时，检查公网可达性、完整回调路径、token 和明文模式。能收不能发时，检查 appId、appSecret、公众号接口权限及平台回复规则。DuDu 不代替平台申请权限或完成审核，不承诺所有公众号类型都具备相同发送能力。
