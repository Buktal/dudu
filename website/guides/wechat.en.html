WeChat Official Account integration

Configure plaintext WeChat Official Account callbacks, receiving tokens and text sending credentials for the DuDu unified inbox.

On this pageScopeConfiguration and validationTroubleshooting and limitsReferences

Scope

This guide covers the wechat-mp adapter for WeChat Official Accounts. It currently supports plaintext callbacks only. WeChat Mini Programs and WeCom use separate adapters and fields. Official Account AES-encrypted callbacks are outside the current scope.

Configuration and validation

  1. Prepare an Official Account with the required messaging API permissions. Configure a public callback origin reachable by the platform.
  2. Create a WeChat Official Account channel in Console and assign a group. Set the receiving token; add appId and appSecret for replies.
  3. Copy the callback URL from Console into the Official Account server configuration. Match the token and select plaintext messages. Complete GET verification before enabling callbacks.
  4. Send a message from a real Official Account user. Check the inbox and history in an authorized employee’s Desk, then send a text reply and inspect the actual platform response.

Troubleshooting and limits

If server verification fails, check public reachability, the complete callback path, token and plaintext mode. If receiving works but replies fail, check appId, appSecret, API permissions and platform reply rules. DuDu does not apply for permissions or platform review, and account types may have different sending capabilities.
