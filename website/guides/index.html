DuDu 使用指南

开源多渠道客服系统的部署、渠道接入、坐席接待与回调联调指南。

部署与本地运行 ↗

从本地 MySQL、Java Server 和三个前端开始运行 DuDu，并了解自托管部署的配置边界。

从企业开通到坐席接待 ↗

了解 Admin、Console 与 Desk 的职责，以及企业、用户组和渠道账号如何组成统一客服工作流。

微信公众号接入指南 ↗

为 DuDu 配置微信公众号明文回调、接收 token 与文本发送凭据，并验证统一工作台接待。

Telegram Bot 接入指南 ↗

区分 Telegram botToken 与 Webhook secretToken，配置 DuDu 回调并验证 Bot 文本消息接待。

WhatsApp Cloud API 接入指南 ↗

了解 WhatsApp Webhook 验证、消息签名与发送凭据如何分别配置到 DuDu 企业控制台。

使用 MockPulse 联调渠道回调 ↗

使用可复现的事件素材、场景、计划和运行记录，验证 DuDu 本地回调与坐席工作流。

指南依据当前实现整理。建议先完成部署与接待流程，再选择渠道接入；各页链接的源码契约保留完整字段与行为说明。
