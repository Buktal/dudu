WhatsApp Cloud API 接入指南

了解 WhatsApp Webhook 验证、消息签名与发送凭据如何分别配置到 DuDu 企业控制台。

本页内容凭据职责配置与验收常见边界参考

凭据职责

接收需要 appSecret 与 verifyToken：verifyToken 用于 GET hub.challenge 握手，appSecret 用于 POST 请求的 X-Hub-Signature-256 签名校验。发送需要 accessToken 与 phoneNumberId。回调 URL 由 Server 派生，在 Console 中只读展示，不是发送 API 地址。

配置与验收

  1. 在 Meta 平台准备 WhatsApp 应用、业务电话号码及相应权限，部署公开可达的回调服务。
  2. 在 Console 新建 WhatsApp 账号并绑定用户组，填写 appSecret 和 verifyToken；需要回复时填写 accessToken 和 phoneNumberId。
  3. 在 Meta 的 Webhook 配置中填写 Console 提供的回调 URL 和相同的 verifyToken，完成验证并订阅所需 WhatsApp 消息事件。
  4. 从真实用户发送测试消息，核对 Desk 来信，再按平台会话规则验证纯文本回复。API 版本与基址属于 Server 部署配置，不由渠道账号 URL 控制。

常见边界

GET 验证成功不代表 POST 签名一定正确，应分别检查 verifyToken 和 appSecret。接收成功不代表 accessToken 拥有所需发送权限，也不代表消息符合 Meta 的会话窗口与账号政策。phoneNumberId 保存后不可换绑；切换电话号码应新建渠道账号。
