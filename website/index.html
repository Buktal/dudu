如何开始使用？

DuDu 目前通过源码构建和自行部署使用，需要具备基本开发与运维能力。先运行服务端，再配置企业和渠道，最后由坐席登录接待。浏览器使用工作台无需构建桌面端。

完整运行指南 ↗
LOCAL DEVELOPMENT ~/dudu 

$ git clone https://github.com/Buktal/dudu.git
$ cd dudu
$ docker compose -f dudu-server/compose.yaml up -d --wait
$ cd dudu-server
$ mvn spring-boot:run
  1. Admin 开通企业，配置初始企业管理员。
  2. Console 配置员工、用户组与渠道账号。
  3. Desk 登录接待，按渠道权限发送回复。

本节为本地开发流程。公开部署前须更换开发凭据和 JWT 密钥。
