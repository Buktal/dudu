开源多渠道客服系统

DuDu 是基于 Apache-2.0 的开源、自托管多渠道客服系统，提供统一坐席工作台、企业控制台、平台管理后台和渠道回调模拟工具。

Capabilities

统一消息接待，明确管理边界

统一接待

集中查看渠道会话与历史消息，接收实时来信，发送纯文本回复，维护共享标签和内部备注。

企业与用户组权限

按企业隔离数据，通过用户组分配员工和渠道账号，按当前授权范围访问会话。

自主部署与扩展

服务端与客户端源码完整公开；基于现有渠道适配结构扩展接入，使用 MockPulse 开展本地协议联调。

Product suite

四个应用，覆盖接待、管理与联调

Java 服务端提供认证、权限、消息持久化、渠道适配和 HTTP / WebSocket 接口，各应用围绕不同使用者划分职责。

Desk

坐席工作台

专注、并排与卡片三种接待模式，支持浏览器运行和 Tauri 桌面构建。 使用文档 ↗

Console

企业控制台

管理员工、用户组与渠道账号；渠道凭据只写入，不回传秘密值。 使用文档 ↗

Admin

平台管理后台

开通企业、管理企业资源，查看运营概览与操作记录。 使用文档 ↗

MockPulse

渠道回调模拟工具

面向开发者的本地桌面工具，用于构造事件、签名与加密回调，组织剧本、编排计划并查看运行结果。运行客服系统无需启动此工具。

MockPulse 使用文档 ↗
Channel adapters

13 种渠道适配器

覆盖以下平台的指定消息体系；各渠道的授权、事件和收发边界不同。

微信公众号 微信小程序 企业微信 钉钉 飞书 QQ 微博 抖音 小红书 支付宝 美团 Telegram WhatsApp

当前工作台仅支持出站纯文本；非文本入站展示按渠道能力处理。生产接入需要部署方完成平台申请、授权和公网验证。项目持续开发中，暂无正式发布包或托管演示。
