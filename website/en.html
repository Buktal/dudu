Messaging capabilities

Plain-text replies are supported; attachment sending is unavailable. Incoming non-text messages and media depend on the channel.

Integration requirements

Obtain channel accounts, complete platform authorization and credential setup, then validate real messaging. Each platform retains its own permissions and rules.

How do you get started?

DuDu currently requires building from source and self-hosting, with development and operations knowledge. Run the server, configure your organization and channels, then sign in as an agent. Browser access does not require a desktop build.

Complete setup guide ↗
LOCAL DEVELOPMENT ~/dudu 

$ git clone https://github.com/Buktal/dudu.git
$ cd dudu
$ docker compose -f dudu-server/compose.yaml up -d --wait
$ cd dudu-server
$ mvn spring-boot:run
  1. Provision an organization and initial administrator in Admin.
  2. Configure employees, groups and channel accounts in Console.
  3. Sign in to Desk and reply within each channel’s permissions.

This is a local development workflow. Replace development credentials and the JWT secret before public deployment.
