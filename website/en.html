Channel configuration & limitations ↗
Development status & current scope

The project is under active development, without release packages or a hosted demo. Incoming non-text content depends on the channel; outbound replies support text only. Production use requires platform approval, credentials, authorization and public end-to-end verification. Configuration alone does not establish working authorization.

Run on your terms.

Development requires Java 21, Maven 3.9, Docker Compose, Node.js 22.12+ and Yarn 4. Desktop builds additionally require Rust and Tauri prerequisites.

Complete setup guide ↗
LOCAL DEVELOPMENT ~/dudu 

$ git clone https://github.com/Buktal/dudu.git
$ cd dudu
$ docker compose -f dudu-server/compose.yaml up -d --wait
$ cd dudu-server
$ mvn spring-boot:run
  1. Provision an organization and initial administrator in Admin.
  2. Configure employees, groups and channel accounts in Console.
  3. Sign in to Desk and reply within each channel’s permissions.

This is a local development workflow. Replace development credentials and the JWT secret before public deployment.
